<h1 align="center">🤖 Rule-Based Chatbot</h1>

<p align="center">
  A simple rule-based AI chatbot built using Python.
</p>

<hr>

<h2>📌 Project Overview</h2>

<p>
This project is a console-based rule-based chatbot developed in Python
as part of the Week 1 AI Assignment.
The chatbot uses predefined rules and keyword matching to understand
user input and provide appropriate responses.
</p>

<h2>✨ Features</h2>

<ul>
  <li>👋 Responds to greetings</li>
  <li>🤖 Explains what Artificial Intelligence means</li>
  <li>😊 Responds to "How are you?"</li>
  <li>👨‍💻 Explains who created the chatbot</li>
  <li>❓ Provides help and available commands</li>
  <li>🚪 Supports exit commands such as <code>bye</code>, <code>exit</code>, <code>quit</code>, and <code>goodbye</code></li>
  <li>⚠️ Handles empty and unknown inputs</li>
</ul>

<h2>💬 Example Interaction</h2>

<pre>
You: hello
Bot: Hello! Welcome. How can I assist your studies today?

You: what is ai
Bot: AI stands for Artificial Intelligence—the simulation of human intelligence by computers.

You: how are you
Bot: I'm operating at peak performance. Thanks for asking!

You: who made you
Bot: I was created as a rule-based Python project for Week 1 AI Assignment.

You: help
Bot: You can ask me about AI, greet me, ask how I'm doing, or type 'bye' to exit.

You: bye
Bot: Goodbye! Have a productive day ahead.
</pre>

<h2>🧠 How It Works</h2>

<ol>
  <li>The chatbot takes input from the user.</li>
  <li>The input is cleaned and converted to lowercase.</li>
  <li>The chatbot checks the input against predefined keywords.</li>
  <li>A suitable response is selected based on the matching rule.</li>
  <li>The conversation continues until the user exits.</li>
</ol>
